## English (en-US)

### Short description

Choose a temporary laptop mode for the moment you are in. Temporary Laptop
Modes restores your previous power settings automatically when you are done.

### Description

Temporary Laptop Modes makes Windows power settings easy to use for real
moments: writing, watching a dashboard, teaching, travelling, running a quiet
long job, or compiling a large project.

Choose a mode from the system tray and carry on. Before changing anything, the
app saves your current power settings. It then restores them when the timer
ends, when you plug the power cable back in, or when you choose Restore normal.

Focus keeps your screen and laptop awake for writing, reading, stocks, and
dashboards. Coding balances responsive development work with quieter CPU
limits. Presentation prevents the screen from turning off. Battery reduces
power use while you travel. Quiet keeps a long-running task awake while letting
the display turn off. Compile Boost temporarily switches to high performance
for demanding builds and tests.

The tray icon always shows the active mode. The app notifies you after your
previous settings are restored, so you never have to remember what you changed.

### Features

Temporary Focus mode for writing, reading, stocks, and dashboards
Temporary Coding mode for editors, terminals, and moderate builds
Presentation mode that keeps the screen awake
Battery mode that ends automatically when power is connected
Quiet mode for servers, downloads, and long-running tasks
Compile Boost for short, demanding builds and tests
Automatic restoration of the previous power settings
Light and dark tray menu that follows the Windows app theme
